## 🧠 About This Repository

This repository is my **daily DSA practice log**.

The goal isn't just to solve problems.

> **The goal is to become consistent enough that solving problems becomes a habit.**

Every problem I solve is committed to this repository and organized according to the **core DSA pattern / technique** used to solve it.

### 🎯 What I'm focusing on

- 🧩 Understanding DSA patterns
- 💡 Improving problem-solving ability
- ⚡ Writing optimized C++ solutions
- 📈 Maintaining a daily coding streak
- 🔍 Revising previously solved problems
- 🎯 Preparing for technical interviews
- 🚀 Building consistency through GitHub commits
